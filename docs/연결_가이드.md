# 연결 가이드 — 코드는 완성, 이것만 연결하면 됨

> 2026-07-06 기준. 모든 기능이 코드로 완성돼 있고, 아래 "연결 작업"만 하면 순서대로 활성화됩니다.
> 새 AI 세션에서 이어서 작업할 때는 이 문서 + docs/MVP_구현계획서.md + docs/테스트_플로우.md를 먼저 읽게 하세요.

## 1. 실행해야 할 SQL (Supabase SQL Editor)

아직 안 했다면 순서대로 전부 실행 (했던 건 IF NOT EXISTS라 다시 실행해도 무해):

```sql
-- M5 뉴스
ALTER TABLE news ADD COLUMN IF NOT EXISTS fetched_at timestamp NOT NULL DEFAULT now();

-- M7 분석
ALTER TABLE analyses ADD COLUMN IF NOT EXISTS risks jsonb;

-- P2 룰 편집
CREATE TABLE IF NOT EXISTS rules (
  id serial PRIMARY KEY,
  name text NOT NULL,
  definition jsonb NOT NULL,
  enabled boolean NOT NULL DEFAULT true,
  created_at timestamp DEFAULT now() NOT NULL
);

-- P2 노트 AI 검토
ALTER TABLE notes ADD COLUMN IF NOT EXISTS ai_review jsonb;
ALTER TABLE notes ADD COLUMN IF NOT EXISTS reviewed_at timestamp;

-- P2 브리핑
CREATE TABLE IF NOT EXISTS briefings (
  id serial PRIMARY KEY,
  slot text NOT NULL,
  market_summary text,
  stock_sections jsonb,
  watch_items jsonb,
  created_at timestamp DEFAULT now() NOT NULL
);

-- M4 한국 종목 검색 (+ 전체 종목 페이지의 US/KR 구분)
CREATE TABLE IF NOT EXISTS stocks_master (
  code text PRIMARY KEY,
  name text NOT NULL
);
ALTER TABLE stocks_master ADD COLUMN IF NOT EXISTS market text NOT NULL DEFAULT 'KR';

-- 뉴스 AI 평가 (호재/악재 + 중요도 + 원칙 관련성)
ALTER TABLE news ADD COLUMN IF NOT EXISTS sentiment text;
ALTER TABLE news ADD COLUMN IF NOT EXISTS importance integer;
ALTER TABLE news ADD COLUMN IF NOT EXISTS ai_note text;

-- 발굴(추천) 결과 저장
CREATE TABLE IF NOT EXISTS discoveries (
  id serial PRIMARY KEY,
  picks jsonb NOT NULL,
  scanned_count integer,
  candidate_count integer,
  created_at timestamp DEFAULT now() NOT NULL
);
```

## 2. 키 연결 → 기능 활성화 매핑

| .env.local에 추가 | 활성화되는 것 | 발급처 |
|---|---|---|
| `FINNHUB_API_KEY` | 미국 시세·재무·뉴스 실데이터 | finnhub.io (즉시) |
| `ANTHROPIC_API_KEY` | AI 분석·노트 검토·브리핑·발굴·노트→룰 전부 실전환 | console.anthropic.com (크레딧 $5) |
| `KIS_APP_KEY`, `KIS_APP_SECRET`, `KIS_ENV=real` | 한국 시세·차트·지표, 발굴의 한국 유니버스 | KIS Developers (승인 1~2일) |
| `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | 한국 종목 뉴스 (자동 활성화) | developers.naver.com (즉시) |
| `DART_API_KEY` | 한국 ROE·부채비율·배당수익률 보강 (+ `node scripts/load-dart-corpcodes.mjs` 1회) | opendart.fss.or.kr (즉시) |

키 변경 후 항상 서버 재시작.

## 3. KIS 승인 후 할 일 (M4 마무리, ~10분)

1. `.env.local`에 KIS 키 3개 추가
2. 한국 종목 검색용 마스터 적재 (1회):
   ```bash
   node scripts/load-krx-master.mjs
   ```
3. `pnpm dev` 재시작 → ⌘K에서 "삼성전자" 검색 → 추가 → 시세·차트·지표 확인
4. docs/테스트_플로우.md 맨 아래 "M4 완료 후 추가 항목" 체크

## 4. 배포 (M8, ~30분)

1. GitHub repo 만들고 push (`.env.local`은 자동 제외됨)
2. vercel.com → Import → 환경변수 등록: DATABASE_URL, FINNHUB_API_KEY, ANTHROPIC_API_KEY, KIS 3종, NAVER 2종 + **아래 2개 추가**:
   - `BASIC_AUTH_PASSWORD=원하는비밀번호` → 전체 사이트 잠금 (src/middleware.ts가 처리)
   - `CRON_SECRET=랜덤문자열` → cron 엔드포인트 보호
3. 배포되면 **cron 자동 등록됨** (vercel.json):
   - 평일 아침 08:00 KST → 아침 브리핑 + 발굴(추천 리스트) 자동 생성
   - 평일 저녁 16:40 KST → 저녁 브리핑 + 발굴 자동 생성
   - 발굴은 ANTHROPIC_API_KEY 있을 때만 실행 (실패해도 브리핑엔 영향 없음)
4. 폰에서 접속 → 홈 화면에 추가 (PWA manifest 적용됨)
5. 최종 검증: docs/테스트_플로우.md 전체 + MVP DoD 시나리오

## 5. 이미 완성돼 있는 기능 전체 목록

- 대시보드: watchlist(미국+한국), 시세 카드, 장 상태, ⌘K 검색(양 시장), 스타터 칩
- 종목 상세: 캔들차트(1M/3M/1Y), 재무지표 8종, 룰 평가, AI 분석(+반론⚠+이력), 뉴스, 관련 노트
- 뉴스: 종목별 + 통합 피드(/news), 한국은 네이버(키 연결 시)
- 노트: 마크다운 에디터, 태그, AI 검토(오류·과잉일반화·반례), 노트→룰 변환, 백업 다운로드
- 설정: 룰 편집 UI, API 키 상태
- 브리핑: 수동 생성(아침/저녁) + 배포 후 자동(cron), 델타 원칙, 주목 종목(근거 필수), 아카이브
- 발굴: 유니버스(미국30+한국20) 룰 스캔 → AI가 내 노트 기준 적합도 평가
- 배포 준비: Basic Auth, PWA, cron 엔드포인트
